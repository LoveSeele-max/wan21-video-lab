## 1. 怎么开始

1. 先在 Excel 的“单视频评分”中填写匿名编号、待评视频位置、提示词和动作要求。每条视频一行。正式盲评时，不在评分表中填写模型、配置、种子或“基线/优化”等身份信息；对应关系单独保存。评分者可以知道提示词。
2. 保持同一播放器、正常速度和相近显示大小。第一遍完整看主体、动作和整体表现，第二遍确认缺陷。观看准备不计入评分耗时，从开始播放到填完该条记录计时。
3. 必要时暂停、逐帧或慢放，在“查看方式”中标记。主要档位依据正常速度可辨认的问题；仅逐帧可见、正常播放不可辨的小缺陷记录在证据里，不单独据此判为明显失败。
4. 分别选三项分数。分数较低或无法判断时，填写问题位置和观察证据。时间写成视频内的秒数，例如 `1.2-1.8 s`，不是电脑时间。全程问题可以写“全程”。
5. 填写评分耗时（秒）、评分者和日期。保留失败、无法播放和无法判断的样本，不删除记录。

分数使用 `2-较好`、`1-有缺陷`、`0-明显失败`、`无法判断`。空白表示尚未评，不能当成 0。三项分别报告，不计算总分或平均质量分。

## 2. 三项单视频评分

| 维度 | 2-较好 | 1-有缺陷 | 0-明显失败 |
|---|---|---|---|
| 画质与结构 | 正常速度下主体清楚，主体数量和关键形状合理，没有明显模糊、融合、破碎或多余肢体 | 有局部模糊、手指融合、纹理错误或轻度变形，但主体及关键动作仍可辨认 | 出现明显多肢体、主体破碎、严重扭曲或模糊，明显破坏主体识别或关键动作判断 |
| 时序与运动自然度 | 运动和镜头连贯，主体身份、服装和外观稳定；人物或动物关节运动无明显异常 | 偶发闪烁、抖动、小幅跳变或不自然运动，整体运动过程仍可理解 | 明显身份切换、镜头跳切、肢体瞬移，或反复/持续的异常关节运动，破坏运动过程 |
| 提示词符合度 | 核心主体和动作满足要求，明确写出的场景、构图及镜头条件基本符合 | 核心主体和动作可辨，但动作未满足完整验收条件，或遗漏场景、构图、镜头等条件 | 核心主体缺失/错误，或核心动作没有发生/变成另一种动作 |

判档原则：

- 明显重大问题即使短暂也可以判 0；轻微问题不因持续较长就自动判 0。依据问题是否破坏该维度的判断，并记录位置和现象。
- 结构看“形状对不对”，时序看“变化是否连贯、合理”，符合度看“有没有做要求的事”。同一缺陷可以影响两项，但要分别说明依据。
- 主体在画面中完全没出现：符合度判 0；不能因为主体缺失而把其他所有维度都判“无法判断”。其他维度按实际可见画面评分。
- 画面平稳但人物不挥手：符合度判 0；不自动把时序也判 0。只有出现跳变、闪烁、运动不自然等可见问题时才相应降低时序档位。
- 蒸汽、火焰、海浪的正常变化不能仅因“有变化”判为闪烁。看是否出现不符合场景的整幅亮暗交替、纹理跳变或运动断裂。
- 清楚可见的失败不能标“无法判断”。不确定的两个相邻档位，复看一次后选有可观察证据支持的档位，并写明犹豫点，不猜测原因。

## 3. 什么情况填“无法判断”

“无法判断”按维度填写，不是给整条视频的豁免。

| 情况 | 记录方式 |
|---|---|
| 关键关节被遮挡，无法看清其运动是否合理 | 时序可填“无法判断”，其他可见维度照评；记录遮挡位置 |
| 明确看到没有目标动作 | 符合度填 0，不填“无法判断” |
| 缺少提示词，无法判断要求是否满足 | 符合度填“无法判断”，记录缺少输入 |
| 视频严重模糊，动作看不清 | 结构可判 0，符合度可为“无法判断”，分别记录理由 |
| OOM 或生成失败 | 观看状态选对应失败类型，分数留空，证据写失败原因 |
| 文件存在但无法播放 | 状态选“无法播放”，分数留空，记录播放器错误；不能算作质量 0 |

## 4. 提示词对应的动作验收条件

下面对应 Week 3 的 12 条提示词草案；提示词正式冻结时同步检查。只检查片段中实际可见的动作，不要求动作超出 81 帧所覆盖的时间。

| ID | 核心事件 | 2 档需要满足的主要观察条件 |
|---|---|---|
| P01 | 人物单手挥手 | 人物与一只挥动的手可辨；手相对前臂或身体至少完成一次可辨认的往返；不能只靠镜头移动 |
| P02 | 女性缓慢点头 | 可辨认头部至少一次向下再返回的运动；主体和慢速要求基本符合 |
| P03 | 男性转身面向镜头 | 开始未正面朝向镜头，随后通过身体转动面向镜头；不能只是剪切换成另一个人 |
| P04 | 人物从左向右行走 | 全身可见，有可辨认的左右脚交替步态和向右位移；不要求走出画面 |
| P05 | 人物原地慢跑 | 全身可见，有可辨认的交替跑步动作，主体整体位置基本保持 |
| P06 | 胸前拍手 | 至少一次双手靠近、可辨认地合拢、再分开；上半身和胸前位置基本符合 |
| P07 | 海浪拍打岩石 | 海浪有推进并撞击岩石的过程；不能只呈现静止海面 |
| P08 | 烛火轻微摇曳 | 火焰形状或位置有可辨变化；整幅画面的亮暗交替不算火焰动作 |
| P09 | 雪山航拍缓慢横移 | 雪山、日出环境基本符合，镜头有连续缓慢横移；跳切不算横移 |
| P10 | 金毛犬奔跑 | 犬的主体特征可辨，有交替跑动与跨草地位移；侧面与跟拍要求基本符合 |
| P11 | 夜间街景车辆经过 | 可辨认夜间城市和灯光，至少一辆车相对街道经过；不能只有灯光闪动 |
| P12 | 杯中蒸汽升起 | 杯子、桌面与蒸汽可辨，蒸汽相对杯口有向上运动；无需其他主体大幅运动 |

动作仅部分发生时填符合度 1，完全未发生时填 0。人物性别、犬种等若因画面无法辨认，不强行猜测，在证据中注明；结合核心主体及动作是否可判断决定档位或“无法判断”。

## 5. 优化前后的配对比较

使用“配对评分”页，每行是一对视频。相同提示词、种子、生成设置配对；A/B 左右随机，评分时不查看配置映射。先独立评价，再比较，不因为知道哪个版本更快而调整质量分。

三项维度分别选择 `A更好`、`无明确优劣`、`B更好`、`无法判断`。比较不是总分投票：A 结构更好、B 动作更好时，分别保留。

| 程度 | 怎么选 |
|---|---|
| 无明显差异 | 方向为“无明确优劣”，正常播放未见明确质量区别 |
| 有差异但难判优劣 | 两者确有区别，但不能明确哪边更好，例如人物外观不同；不把纯外观变化自动当退化 |
| 轻微 | 方向为 A 或 B 更好，差别局部且不改变该维度的可用性 |
| 明显 | 方向为 A 或 B 更好，差别破坏主体结构、运动理解或核心动作判断 |
| 无法判断 | 该维度无法观察，或缺少可比较条件，写明原因 |

配对也要保留视频内时间和证据。A/B 映射在评分结束后解盲，才转换为“优化更好/无明确优劣/优化更差”。不合并三项为总胜率，不事后只挑有利维度。
