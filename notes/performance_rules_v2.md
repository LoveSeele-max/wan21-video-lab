# 未来性能实验操作规则 v2

日期：2026-11-06，Asia/Shanghai。适用范围：未来实验的事前设计模板。新实验必须在运行前通过独立预登记明确引用本文件、指定候选与目标，才适用本规则。

Week4–5 继续按原规则分类，不用 v2 重判 Sage 或两种 FP8。本文未触发新实验，也不改变质量与可靠性规则。

## 为什么另写版本

原规则先发现两组 min/max 相交，再追加并合并全部数据，要求合并范围不相交。旧区间被合并区间包含，已有交集不会因新增样本消失。v2 取消这种追加判定，保留 min/max 作为波动描述，不把范围相交视为速度结论的必要条件。

## 固定采样与判定

1. 每个候选使用当期同环境、同物理 GPU 的基线；固定模型、输入、种子、精度和计时边界，无其他计算任务。环境、进程及设备状态须记录；不跨环境比较绝对秒数。
2. 预先固定六个相邻对照区组，每区组各一次基线 B 和候选 C，顺序固定为 `BC, CB, CB, BC, BC, CB`。每次使用独立进程，预热一次、正式测量一次；共十二个正式值及十二次预热。阶段插桩/快照另作诊断，不混入正式 total。
3. 对区组 i 计算耗时降幅 `r_i = 1 - C_i/B_i`。六对全部保留，报告各原值、配对降幅、各侧均值与 min/max、六个降幅的中位数，不挑最快一次。
4. 只有同时满足以下三条，才记“达到本项目速度门槛”：六个配对降幅的中位数至少 5%；两侧全部正式值的均值降幅至少 5%；至少五对候选耗时低于基线。否则记“未达到”，不在同一实验追加至通过。
5. 六对是重复测量同一固定任务，不是六个独立提示词。上述是工程操作规则，不是显著性、置信区间或总体等价性检验，不外推其他输入/硬件。

## 异常、显存与质量

- 崩溃、并发干扰或版本不一致均保留原证据，该轮标为无效，不删除单个慢值后继续凑数。必要的新一轮须先写偏差与完整新运行计划，原轮仍在报告中。
- allocated、reserved 和整卡采样分别报告；固定重置及同步边界。整次与阶段峰值分开，不把阶段峰值相加，采样频率及可能漏峰要注明。
- VAE 单独解码的测量不得冒充整次生成性能；记录 latent 身份、dtype、shape、缓存与上下文。快照/hook 的工具开销单列。
- 显存为主要目标时，新实验须事先指定具体口径、最低降幅及可接受耗时增幅。本模板不替尚未定位的改法预设收益。
- 质量与可靠性须在新实验运行前另行引用或登记。速度达到本条门槛不自动得到“可用”，也不替代输出差异验证。
