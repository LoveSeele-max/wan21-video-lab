# 基座动作预检（BASELINE PROBE）

**版本**：V2.1，2026-10-11（V2.1 修正了第一节与第五节的措辞冲突，以及第八节的表述）。**作用已改变**：换题前它是"选题筛查 + 研究时间步分布的前提"；现在它是**训练阶段（第 11-12 周）选动作的依据**，范围大幅缩小。

**项目**：Wan2.1 1.3B 单卡推理优化与窄域适配。

**目的**：在筛数据、训 LoRA 之前，观察基座在候选简单动作上的表现与成本，决定**哪个动作值得花训练预算**。

**定位**：这是**选题筛查**，不是能力穷尽测试，也不是 LoRA 可训练性证明。多次失败不证明模型完全不会，少量成功不证明能力饱和，有可见缺陷也不保证 LoRA 能修复。

**纪律**：不训练、不下载训练素材。本文件不含具体提示词与种子取值——那些在跑之前确定并登记。

---

## 一、为什么要做这个预检

按预算考虑：基座在某个动作上**已经做得很好**，盲评就较难看出改善；**完全做不出来**，单个 LoRA 修好它的风险较高。两者都不是"不可能"，只是性价比低（结论强度见第五节）。性价比最高的是中间地带：

> **能完成，但反复出现同类缺陷。**

那才是适配能起作用的地方，也才是盲评能看出差异的地方。预检就是把这个中间地带找出来。

## 二、候选动作

| 类别 | 动作 | 观察重点 |
|---|---|---|
| 低复杂 | 挥手、点头、转身 | 能否完成、结构是否稳定 |
| 中复杂 | 行走、跑步 | 肢体协调、运动连续性 |

单人物，固定背景，固定镜头。**不引入以人物图片或姿态为条件的入口**——那需要换项目，不是当前 LoRA 路线能覆盖的。

## 三、每条样本记录六项

| # | 记录项 | 要能被人复核的观察 |
|---|---|---|
| 1 | 动作是否发生 | 是 / 否 / 部分 + 证据；观察不清记无法判断 |
| 2 | 是否满足片段内判据 | 挥手检查一次往返；持续行走检查有效步态是否持续，**不要求"走完"** |
| 3 | 人体结构是否稳定 | 肢体数量、关节连续性有无帧间崩坏（多手、肢体骤变） |
| 4 | 片段内身份与服装是否漂移 | **只判单条视频内一致性**，不跨条比对身份 |
| 5 | 时序缺陷与指令符合度 | 闪烁、运动塌缩、镜头跳变分别记；要求未发生记"指令不符合" |
| 6 | 单条耗时与峰值显存 | 与主线测量脚本**共用同一口径**，不另建一套 |

第 6 项复用主线的 `scripts/bench.py`，不要为预检单独写测量代码。

## 四、标签：三类分开

| 类别 | 例子 | 原则 |
|---|---|---|
| **时序/结构缺陷** | 肢体数量突变、关节跳变、闪烁、片段内换人换衣 | 标出缺陷及发生位置；静止或停顿是否异常须结合动作要求 |
| **指令不符合** | 要求挥手却没挥手 | **不自动归为时序不稳定**；重复挥手不算故障 |
| **无法判断** | 严重遮挡、片段过短、观察不清 | 只对无法判断的维度标记，**不把整条视频从记录中删除** |

标签可正交：严重模糊时动作可记无法判断，画质仍可记明确缺陷。

## 五、结论强度

| 观察 | 可支持的决定 | 不能推出 |
|---|---|---|
| 某动作多次失败 | 按预算不优先，或保留待查 | 模型完全不会、LoRA 学不了 |
| 少量样本表现良好 | 暂未发现改善空间，降低优先级 | 能力已饱和、适配一定无用 |
| **能完成但反复出现缺陷** | **列为适配候选，明确主要缺陷** | 缺陷一定可由 LoRA 修复 |
| 动作出现但结构常崩 | 评估动作表现与结构稳定性的取舍 | 只要微调就会改善 |

**预算决定不是能力定理**：可以为降低风险而暂不选某动作，但不能写成"模型无法学习"。

## 六、产出

1. 原始生成视频（按动作归档）；
2. 每条样本的六项记录与三类标签；
3. 各维度三档占比 + 耗时与峰值显存；
4. **一个决定**：哪个动作进入数据筛选，附证据、局限与成本。

## 七、两处已知混淆（先声明）

1. **时长混淆**：片段过短可能让动作判据无法应用。标记受限，**不自动认定是模型缺陷，也不自动认定由帧数造成**。
2. **样本量混淆**：多种子只用于观察出片波动，仍是小样本筛查，不能证明模型完全不会或已经饱和。

## 八、与主线的边界

- 预检**不另建测量口径**，只复用主线脚本记录单条耗时与峰值显存（第三节第 6 项）。延迟与显存的分析是主线的工作。
- 预检的观察**不能**充当训练后的独立测试证据。
- LoRA 在本项目配置中能否影响动作、影响多大，留给训练后的盲评回答。
